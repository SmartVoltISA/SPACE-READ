# SPACE-READ

**Публичный read-only слой архитектуры SPACE для людей, исследователей и внешних ИИ.**

SPACE-READ — это контролируемый публичный слой публикации, а не копия и не рабочее ядро SPACE. Внешний человек или ИИ может читать опубликованные материалы, анализировать их, использовать архитектурные идеи и предлагать изменения. Эталонный SPACE Core при этом остаётся за пределами публичного write-контура.

## Граница

```text
SYSTEM-FOUNDATION
       ↓
   SPACE Core
       │
       │ controlled publication
       ▼
   SPACE-READ
       │
   ┌───┼─────────┐
   ▼   ▼         ▼
 HUMAN RESEARCH  AI

      write-back: NONE
```

Публичность репозитория не означает право записи в Core. Fork или производная реализация также не являются оригинальным SPACE.

## Что уже есть

- `PUBLICATION_CONTRACT.md` — правила публикации;
- `AI_INTERFACE.md` — контракт для внешнего ИИ;
- `PROPOSAL_PROTOCOL.md` — как оставлять предложения и результаты;
- `PUBLICATION_INDEX.json` — машинно-читаемый индекс;
- `schema/publication.schema.json` — схема публикационного объекта;
- `publications/space/ARCHITECTURE_OVERVIEW.md` — первая публичная публикация архитектуры;
- `READ_ONLY_POLICY.md` — read-only инварианты;
- `SECURITY_ARCHITECTURE.md` — физическая граница безопасности;
- `RECOVERY_PROTOCOL.md` — правила восстановления;
- `ROADMAP.md` — план развития;
- `STATUS.md` — текущее состояние;
- `manifest.json` — машинная точка входа.

## Как читать SPACE-READ внешнему ИИ

Рекомендуемый порядок:

1. `manifest.json`;
2. `PUBLICATION_CONTRACT.md`;
3. `READ_ONLY_POLICY.md`;
4. `SECURITY_ARCHITECTURE.md`;
5. `PUBLICATION_INDEX.json`;
6. опубликованные объекты по их идентификаторам.

ИИ должен сохранять статус и provenance материала. `proposal` не является `accepted change`, гипотеза не является подтверждённым фактом, а публикация не означает универсальную истинность.

## Как оставить след

Внешний ИИ или исследователь может создать независимый fork, Issue или Pull Request и оставить:

- предложение;
- исправление;
- эксперимент;
- независимую репликацию;
- контрпример;
- альтернативную реализацию.

Это остаётся внешним предложением до проверки и отдельной публикации. Прямой записи в SPACE Core нет.

## Важное ограничение

SPACE-READ сейчас является Git-репозиторием с документационным и машинно-читаемым слоем. Отдельный сетевой Read API пока **не считается реализованным**. API можно построить позже поверх этого же контракта.

Мы не смешиваем гипотезы с фактами, не переписываем историю задним числом и не называем реализованным то, что пока только запланировано.
